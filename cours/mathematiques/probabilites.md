# Probabilités et statistiques

Les probabilités et les statistiques servent à raisonner sur des données et sur l'incertitude. En terminale STI2D, elles sont utiles pour lire des mesures, estimer un risque, comparer des essais ou interpréter des résultats expérimentaux. Il faut distinguer ce qui est théorique de ce qui est observé.

La règle de base est simple: nommer l'événement, compter les cas, vérifier le résultat et le traduire dans une phrase claire.

## Objectifs du chapitre

- Lire des données simples sans se tromper.
- Calculer une probabilité de base.
- Interpréter un résultat statistique dans un contexte STI2D.

## Ce qu'il faut savoir

- Une probabilité mesure la chance qu'un événement se produise.
- Une fréquence observée n'est pas forcément égale à la probabilité théorique, mais elle peut s'en approcher.
- Les données doivent toujours être lues avec attention.

Les probabilités sont très utiles quand on étudie un risque, une fiabilité ou une répétition d'événement. Les statistiques servent plutôt à résumer des données réelles: moyenne, répartition, tendance, valeur aberrante. Dans un sujet STI2D, tu peux avoir les deux: une probabilité pour le modèle, une statistique pour l'observation.

Ce chapitre demande de la rigueur dans le vocabulaire. On ne dit pas "ça a l'air probable" sans calcul. On nomme l'événement, on compte, puis on conclut.

## Définitions importantes

- Événement: résultat ou ensemble de résultats possibles.
- Cas favorable: issue qui réalise l'événement.
- Cas possible: issue totale de l'expérience.
- Fréquence: proportion observée dans une série.

## Formules importantes

- $p = \dfrac{\text{cas favorables}}{\text{cas possibles}}$
- Une probabilité est comprise entre $0$ et $1$.

## Méthodes types

- Identifier les cas possibles.
- Compter les cas favorables.
- Écrire la fraction ou le décimal.
- Vérifier que le résultat est cohérent.

## Lecture de la méthode

Commence toujours par écrire clairement l'événement. Ensuite, vérifie si les issues sont équiprobables. Si ce n'est pas le cas, il faut une autre méthode. En statistiques, lis d'abord les effectifs ou les fréquences avant de faire une conclusion.

Le but n'est pas seulement de donner un nombre. Il faut expliquer ce que signifie ce nombre dans la situation: risque faible, chance sur deux, fréquence stable, ou au contraire dispersion importante.

## Exemple simple corrigé

On lance un dé équilibré.

- Événement: obtenir un nombre pair.
- Cas favorables: $2, 4, 6$ soit $3$ cas.
- Cas possibles: $6$

Probabilité:

- $p = \dfrac{3}{6} = \dfrac{1}{2}$

## Erreurs fréquentes

- Oublier tous les cas possibles.
- Mélanger fréquence et probabilité.
- Ne pas simplifier une fraction simple.
- Mal lire l'énoncé.
