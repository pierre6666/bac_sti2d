# Binaire et codage

Le binaire est la base de l'information dans les systèmes numériques. En SIN, il faut savoir passer d'une écriture à l'autre, comprendre pourquoi l'information est codée en bits et relier ce codage à des usages concrets: nombres, états logiques, messages ou données stockées.

## Objectifs du chapitre

- Comprendre le principe du binaire.
- Convertir une petite valeur simple.
- Lire le rôle du codage dans un système.

## Ce qu'il faut savoir

- Un bit vaut 0 ou 1.
- Plusieurs bits permettent de coder des nombres et des états.
- Le codage dépend de l'usage.

Le binaire est la base de l'information numérique. En SIN, il est indispensable parce qu'un système électronique travaille avec des états simples. Comprendre ce principe aide à lire les nombres, les états logiques et les données stockées ou transmises.

## Définitions importantes

- Bit: plus petite unité d'information.
- Octet: groupe de 8 bits.
- Codage: manière de représenter une information.

## Méthodes types

- Compter les puissances de 2.
- Relier un mot binaire à une valeur décimale.
- Expliquer ce que représente le code dans le système.

## Lecture de la méthode

Le passage du binaire au décimal consiste à repérer les poids des bits. Cette logique doit être maîtrisée avant de parler de codage plus complexe. Le but n'est pas de réciter une table, mais de comprendre comment la machine représente l'information.

## Exemple simple corrigé

Le code $101$ en binaire vaut $5$ en décimal.

Conclusion:

- Le codage binaire permet de représenter une information simple avec deux états.

Dans un système réel, ce principe sert à tout: mesure, commande, stockage et communication.

## Erreurs fréquentes

- Confondre bit et octet.
- Oublier les puissances de 2.
- Ne pas relier le code à l'utilisation réelle.
