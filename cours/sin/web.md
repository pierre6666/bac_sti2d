# Environnement Web

L'environnement Web apparaît dans la terminale SIN parce qu'il permet de publier, afficher ou consulter des informations techniques à distance. Ce chapitre relie l'interface utilisateur, les données et la communication. Il aide à comprendre qu'un système numérique ne se limite pas au code interne: il doit aussi présenter ses données de manière lisible.

## Objectifs du chapitre

- Comprendre le rôle d'une interface Web.
- Distinguer présentation et données.
- Relier le Web à un système technique.

## Ce qu'il faut savoir

- Une page Web affiche des informations.
- Un formulaire permet de saisir des données.
- Un système peut envoyer ses mesures vers une interface.

## Définitions importantes

- Interface: espace de communication avec l'utilisateur
- Formulaire: zone de saisie de données
- Client: navigateur qui affiche la page
- Serveur: machine qui fournit la page ou les données

## Méthodes types

- Identifier ce que l'utilisateur voit.
- Distinguer les données brutes et leur présentation.
- Expliquer comment une mesure devient un affichage.

## Développement du cours

Dans un système SIN, le Web sert souvent d'interface de consultation ou de contrôle. Par exemple, une serre peut afficher sa température, son humidité ou l'état d'un appareil. Le navigateur ne fait que montrer les données, mais il joue un rôle important: il rend le système accessible et compréhensible.

Il faut donc bien séparer l'information technique elle-même de sa représentation graphique. Une valeur affichée sur une page Web n'est pas la mesure brute: c'est une mise en forme destinée à l'utilisateur.

## Exemple simple corrigé

Une station connectée envoie la température vers une page Web.

- Le capteur mesure
- Le système transmet la donnée
- Le navigateur affiche la valeur

Conclusion:

- Le Web sert ici d'interface de consultation simple.

## Erreurs fréquentes

- Confondre page Web et base de données.
- Oublier la différence entre affichage et donnée brute.
- Croire qu'une interface remplace le capteur.

## Mini quiz de 5 questions

1. À quoi sert une interface Web ?
2. Qu'est-ce qu'un formulaire ?
3. Quelle différence entre client et serveur ?
4. Pourquoi utiliser le Web dans un système ?
5. Pourquoi distinguer affichage et donnée brute ?

## Réponses du mini quiz

1. À afficher ou saisir des informations.
2. À recueillir des données utilisateur.
3. Le client affiche, le serveur fournit.
4. Pour consulter ou contrôler un système à distance.
5. Parce que l'affichage est une mise en forme.
