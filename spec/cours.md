# Spécification - Partie Cours

## Rôle demandé

Tu es chargé uniquement de créer la partie "cours" d'un site personnel de révision pour un élève de Terminale STI2D.

## Objectif

Rédiger des cours clairs, sérieux, progressifs et utiles pour réviser le bac STI2D.

## Matières prioritaires

- Mathématiques
- Physique-chimie
- 2I2D
- SIN si pertinent

## Contraintes importantes

- Ne pas copier les cours mot pour mot.
- Ne pas aspirer massivement les contenus.
- Utiliser les sources pour comprendre le programme, les notions, les méthodes et les attendus.
- Rédiger des cours originaux, reformulés, adaptés à un élève de Terminale STI2D.
- Citer les sources utilisées pour chaque matière ou chaque chapitre.
- Ne pas utiliser de contenu payant ou protégé sans autorisation.
- Si une source est inaccessible ou trop limitée, l'indiquer dans les notes.

## Méthode obligatoire

1. Analyser d'abord les sources et le programme officiel.
2. Identifier les chapitres importants pour le bac STI2D.
3. Classer les chapitres par matière.
4. Rédiger ensuite les cours progressivement.
5. Relire chaque fiche pour vérifier qu'elle est claire, exacte et utile.

## Format attendu pour chaque cours

- Titre du chapitre
- Objectifs du chapitre
- Ce qu'il faut savoir
- Définitions importantes
- Formules importantes
- Méthodes types
- Exemple simple corrigé
- Erreurs fréquentes
- Mini quiz de 5 questions
- Réponses du mini quiz
- Liens ou sources utiles

## Style attendu

- Explications simples.
- Niveau Terminale STI2D.
- Ton pédagogique.
- Pas de blabla inutile.
- Beaucoup d'exemples concrets.
- Rappels de base quand nécessaire.
- Mise en avant des méthodes pour gagner des points au bac.
- Attention particulière aux élèves en difficulté en maths, physique-chimie et 2I2D.

## Contenu minimum attendu

- Une page index par matière avec la liste des chapitres.
- Plusieurs fiches complètes par matière.
- Une page sources.
- Une page notes-recherche expliquant les sources consultées et les choix de contenu.
- Ne pas laisser de page vide.
- Si un chapitre doit être complété plus tard, mettre une section TODO claire avec ce qu'il manque.

## Qualité attendue

- Ne pas se précipiter.
- Ne pas générer du contenu générique.
- Vérifier que les notions correspondent bien au niveau Terminale STI2D.
- Éviter les erreurs de programme.
- Privilégier des cours courts mais vraiment exploitables.
- Les fiches doivent pouvoir être utilisées directement pour réviser.
