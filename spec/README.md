# Spec

Ce dossier contient le cahier des charges fonctionnel du projet, séparé de `AGENTS.md`.

- `spec/site-complet.md` décrit le produit global: site de révision, planning, fiches, tests, suivi, méthode et Grand Oral.
- `spec/planning.md` décrit le besoin produit pour le planning.
- `spec/grand-oral.md` décrit le besoin produit pour la préparation du Grand Oral.
- `spec/suivi.md` décrit le besoin produit pour le tableau de bord de progression.
- `AGENTS.md` décrit les règles de travail, les contraintes d'exécution et les conventions de maintenance.
- `spec/cours.md` décrit le besoin produit pour la partie cours du site de révision STI2D.
- `spec/fiches.md` décrit le besoin produit pour les fiches de révision.

Cette séparation permet de garder :
- des règles d'agent stables ;
- une spécification métier lisible ;
- une base de référence simple à mettre à jour.
